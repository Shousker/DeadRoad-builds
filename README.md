# Dead Road — тестовые сборки

Кооперативная игра про зомби-апокалипсис, до 4 игроков. Здесь только готовые сборки для тестов с друзьями, без исходного кода.

**Скачать:** раздел [Releases](https://github.com/Shousker/DeadRoad-builds/releases/latest) → файл `DeadRoad_v0.56.10.zip` в блоке Assets.

Это прототип: всё в простых формах, баги ожидаемы.

## Как играть

### 1. Что поставить
1. **Архив с игрой** — скачайте в Releases (ссылка выше). Распакуйте в любую папку (путь лучше без русских букв, например `C:\Games\DeadRoad`). Запускать `DeadRoad.exe`. Игра без цифровой подписи, поэтому Windows может показать «Система Windows защитила ваш компьютер» — нажмите «Подробнее» → «Выполнить в любом случае».
2. **Radmin VPN** (бесплатно, radmin-vpn.com) — делает «общую локальную сеть» через интернет, без настройки роутера.
   - Хост: «Сеть» → «Создать сеть», придумать имя и пароль, сообщить их остальным.
   - Остальные: «Сеть» → «Присоединиться к сети», то же имя и пароль.
   - В списке сети у каждого виден IP вида `26.x.x.x`. Нужен **IP хоста**.

### 2. Как зайти
1. Запустите `DeadRoad.exe`, введите своё имя (его увидят над головой). У всех имена должны быть разные.
2. **Хост** нажимает «Создать игру». При первом запуске Windows спросит про брандмауэр — **разрешить** (частные и общественные сети), иначе к нему не подключиться.
3. **Остальные** вводят IP хоста из Radmin и нажимают «Подключиться».
4. Если не пускает: проверьте, что все в одной сети Radmin, что брандмауэр у хоста разрешил игру (порт UDP 7777), и что у всех одна и та же версия архива.

Хост выходит — игра заканчивается у всех. Вышедший игрок может зайти снова под **тем же именем** и получит своё снаряжение.

### 3. Управление
| Что | Клавиша |
|---|---|
| Ходить, бег, прыжок, присед | WASD, Shift, Space, Ctrl (паркур: бег по стене, подтягивание, подкат — подсказки на экране, F1 — скрыть) |
| Вид от 1-го / 3-го лица | V |
| Инвентарь | Tab (тащить мышью, R — повернуть, Ctrl+клик — быстро переложить, Shift+тащить — разделить, ПКМ — меню) |
| Подобрать / открыть шкаф, тело, склад, багажник | E (смотреть на предмет) |
| Выбросить вещь | G (Shift+G — всю стопку) |
| Оружие и быстрые слоты | 1–0, колесо мыши |
| Сесть в машину / выйти | F (второй садится пассажиром) |
| Ремень, сигнал | B, H |
| Возродиться после смерти | Enter |
| Меню (выход) | Esc |
| Краулер: кресло пилота | F у кресла в рубке; C — ход, T — скорость (Shift+T — меньше) |
| Краулер: аппарель, турели, модули | Z, Y, U (у пульта в ангаре) |
| Краулер: насос из бензовоза или бочек, заправить машину в ангаре | P, O |

### 4. Что делать в игре (20–30 минут)
1. Все появились у Краулера (огромная гусеничная база). Осмотритесь, проверьте, что видите друг друга и имена.
2. Один садится в кресло пилота и ведёт Краулер на восток по магистрали (C, T).
3. Двое–трое садятся в маслкар в ангаре (аппарель — Z), съезжают и едут в ближайший город.
4. В городе: шкафы и шкафчики в домах — E, обыск идёт, пока окно открыто (вещи появляются по одной; второй игрок ждёт, пока первый закончит). Найденное «не осмотрено» — ПКМ → Осмотреть.
5. Отбивайтесь от зомби: они идут на шум (стрельба, мотор, обыск). Ночью и в городах их больше.
6. Догоните Краулер, заедьте в ангар, сложите добычу на **склад** (шкаф у левой стены ангара, общий для всех) или в **багажник** машины.
7. Запчасти сдайте на металлолом и поставьте модуль (U у пульта).
8. Если кто-то погиб: его вещи остаются на **теле** (тёмный мешок с его именем), он возрождается в ангаре пустым. Тело может обыскать любой.

### 5. Куда писать о багах
Пишите в общий чат сразу, коротко: **что делали → что ожидали → что случилось**, примерное время и скриншот (Win+Shift+S). После игры каждый присылает свой лог:
`%USERPROFILE%\AppData\LocalLow\DefaultCompany\DeadRoad\Player.log` (вставьте путь в адресную строку проводника). **Лог хоста важнее всего.** Если игра перезапускалась, рядом лежит `Player-prev.log` с прошлого запуска.
